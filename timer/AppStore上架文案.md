# App Store 上架文案

## 📝 描述（Description）
**限制：最多4000字符**

把时间当朋友，让每一分钟都有意义。

Timer App 不仅仅是一个时间记录工具，更是一个帮助你认知时间、反思时间、改进时间使用质量的智能伙伴。我们深受《把时间当朋友》理念启发，将时间管理智慧融入到产品设计中。

【核心功能】

自动时间记录
- 智能自动记录：切换应用时自动记录时间戳，无需手动操作
- 零负担使用：让记录成为习惯，而不是负担
- 专业计时器：支持番茄时钟，开启高效专注模式
- 灵活计时：支持正计时与倒计时，适应多种任务场景
- 沉浸体验：支持横屏展示，大屏显示更专注
- 个性化主题：提供多种主题风格，随心切换
- 实用显示：支持在计时界面同步显示系统时间

活动管理
- 灵活的活动类型：创建、编辑、管理你的活动分类
- 快速标记：常用活动一键选择，3秒完成标记
- 个性化设置：自定义活动名称、图标、颜色

数据统计
- 今日统计：清晰查看各活动时长汇总
- 历史记录：按日期浏览过去的时间线记录
- 直观展示：简单易用的列表视图，一目了然

记录管理
- 手动补录：遗漏了也没关系，随时可以补录
- 灵活编辑：修正错误记录，保持数据准确
- 安全删除：二次确认防止误删

【为什么选择 Timer App？】

1. 基于《把时间当朋友》的核心理念
我们不仅帮你记录时间，更帮你理解时间、投资时间、与时间做朋友。真实记录，不自欺，看清时间真实去向。

2. 自动记录，零负担
智能监听应用生命周期，前后台切换时自动记录。你只需要在切换后选择活动类型，3秒完成标记。

3. 简约现代的设计
遵循iOS设计规范，柔和的渐变色，细腻的阴影和光泽，充足的留白和呼吸感。流畅的动画效果，自然的过渡，60fps流畅度。

4. 持续改进的承诺
第一阶段已完成核心功能，后续将持续推出时间投资分类、质量评价、可视化图表、每日反思等高级功能。

【适用人群】

适合你，如果你：
- 想了解自己的时间真实去向
- 希望提高时间使用效率
- 喜欢用数据了解自己
- 需要一个简单易用的时间记录工具
- 希望形成更好的时间使用习惯

【未来规划】

即将推出：
- 时间投资分类（投资型/消费型/必需型/浪费型）
- 时间质量评价（专注度、有效性）
- 可视化图表（饼图、柱状图）
- 每日反思功能
- 目标设置和追踪
- 趋势分析

【使用建议】

新手入门：
1. 下载后立即开始使用，让app自动记录
2. 创建5-10个常用活动类型
3. 每天睡前查看今日统计
4. 遗漏了也没关系，可以手动补录

我们的承诺：
- 隐私保护：你的数据只属于你，本地存储，安全可靠
- 持续改进：根据用户反馈持续迭代
- 理念坚持：始终围绕"把时间当朋友"的核心理念

时间是最公平的资源，每个人每天都有24小时。但如何用好这24小时，决定了人与人之间的差距。

Timer App 帮助你：
- 看清时间的真实去向
- 有意识地投资时间
- 看到自己的成长轨迹
- 形成更好的时间使用习惯

让我们一起，把时间当朋友！
